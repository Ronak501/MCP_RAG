# Tools & Utilities
CLI helpers, quickstart, and run scripts.

- `quickstart.py` ([quickstart.py](../quickstart.py)) — interactive quick-start guide.
- `surveillance_examples.py` ([surveillance_examples.py](../surveillance_examples.py)) — example usage scripts.
- `run_laptop_camera.py` ([run_laptop_camera.py](../run_laptop_camera.py)) — run with laptop webcam.
- `run_comparison.py` ([run_comparison.py](../run_comparison.py)) — automated baseline comparisons.
- `show_logs.py` ([show_logs.py](../show_logs.py)) — view alerts and detection logs.
- `analyze_logs.py` ([analyze_logs.py](../analyze_logs.py)) — inspect evaluation summaries.
- `utils.py` ([utils.py](../utils.py)) — helper functions (frame extraction, discover videos).
